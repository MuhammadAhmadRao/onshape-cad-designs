# Texas Map

![Texas Map render](images/render.png)

## About
A raised map of Texas created from an imported outline, with embossed lettering. Includes an early V1 and the final version.

## Techniques used
- Importing/tracing an outline into a sketch
- Extrude to a clean thickness
- Text sketch and emboss/extrude
- Version iteration (V1 to final)

## Design notes
- Units: millimeters
- Design intent: the part is for practicing to make designs that we can sketch on and create what we want

## What I learned
- Working with imported geometry and cleaning it up
- Iterating on a design across versions
