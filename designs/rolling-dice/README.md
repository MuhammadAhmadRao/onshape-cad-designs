# Rolling Dice

![Rolling Dice render](images/render.png)

## About
A six-sided die with pips on each face.

## Techniques used
- Cube from a sketch and extrude
- Hole/cut features for the pips
- Patterns and mirroring
- Fillets for rounded edges
